# AALM Catalog Service

![Language Badge](https://img.shields.io/badge/Java-ED8B00?style=for-the-badge&logo=openjdk&logoColor=white)

## 📝 Description
A microservice for managing product catalogs in a distributed e-commerce ecosystem at FHNW.
This project was built as part of my studies (Wirtschaftsinformatik @ FHNW) or as a personal learning project.

## 🛠️ Tech Stack
- **Language:** Java
- **Frameworks & Tools:** Java, Spring Boot, Maven, Spring Data JPA, REST APIs, H2 Database.

## 🚀 Key Features
- RESTful endpoints for catalog items
- Validation and error handling
- Docker integration for containerized deployment

## 💻 How to Run / Build
To get started with this repository locally:
```bash
mvn clean install
mvn spring-boot:run
```
